# Swift Source Links

Swift source links resolve declarations and type members through the shared source parser, validation, and code-reference scanner.

## Extracts declarations and members

Verify Swift declarations, nested types, extension members, enum cases, and escaped names with accurate source ranges, while excluding local declarations.

## Validates links and scans code mentions

Verify Swift wiki links resolve through Markdown validation, missing members fail, resolved methods retain their source ranges, and Swift comments participate in code-reference discovery.
